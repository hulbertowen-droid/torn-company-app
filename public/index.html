Intelligence & Battle Stats ▼
Estimated stats are calculated using an algorithm based on public Torn data like Xanax/refill usage and account age. Please understand these are not perfect and should be treated as guidelines rather than absolute truth. Because the system processes players individually to ensure API safety, it may take several minutes for accurate estimates to appear for everyone on the board.

Correction System: If you have an enemy's verified battle stats, click any yellow stat badge to input an enemy's *actual* battle stats to override the estimate.
