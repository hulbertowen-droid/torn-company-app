    DIBS Script Setup

    To call dibs and appear on the Automatic Chain Order above, install the Faction Dibs script into your browser or PDA.

    Download / Install Script

    PC / Desktop (Tampermonkey)

    1. Install the Tampermonkey extension for your browser.
    2. Click the Download button above. Tampermonkey will intercept it.
    3. Click Install on the Tampermonkey page.
    4. Go to Torn Faction page and click the floating DIBS SETTINGS button in the bottom left corner.

    Mobile (Torn PDA)

    1. Open Torn PDA and go to Settings -> Advanced browser settings.
    2. Tap Manage scripts.
    3. Tap the + button and select Import from URL.
    4. Enter the exact URL of the script link above (long press the download button and copy link).
    5. Save the script and enable it. Refresh the faction page.
