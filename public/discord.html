📖 How to set up a Faction Discord Bot ▼
  1. Go to the Discord Developer Portal → click New Application. Name it something like Faction Alerts.
  2. Click Bot in the sidebar → click Reset Token, copy the token, and paste it into Bot Token below.
  3. Under Privileged Gateway Intents, enable Presence Intent, Server Members Intent, and Message Content Intent. Save Changes.
  4. Go to OAuth2 → URL Generator. Under Scopes check bot and applications.commands. Under Bot Permissions check Send Messages, Embed Links (required for alert cards), and Mention Everyone.
  5. Copy the generated URL and open it to invite the bot to your server.
  6. In Discord, enable Developer Mode (User Settings → Advanced). Right-click your alert channel → Copy Channel ID. Paste it below.
  7. Optionally right-click your Discord profile → Copy User ID to receive direct @mentions for chain alerts.
⚠️ Embed Links permission required. If the bot role is missing Embed Links in your server or channel, Discord blocks rich alert cards. Go to Server Settings → Roles → Bot Role and enable Embed Links and Send Messages.

🔒 How to Setup Channel Locking in Discord

Keep channels hidden until verified

Follow these 4 quick steps in your Discord server to ensure unverified users cannot view any channels until they verify:

  1. Lock Everyone Out: In Discord Server Settings → Roles → @everyone: Set View Channels to OFF (❌ Denied).
  2. Unlock Verification Channel: Right-click your #verification (or #welcome) channel → Edit Channel → Permissions: Set @everyone to View Channel: ON (✅) and Send Messages: ON (✅).
  3. Grant Server Access to Verified: In your server categories or channel permissions: Add your @Verified role and set View Channels: ON (✅).
  4. Enable Bot Privileged Intent: In the Discord Developer Portal → your Bot application → Bot tab → under Privileged Gateway Intents: Toggle SERVER MEMBERS INTENT to ON.
  5. Position Bot Role on Top: In Server Settings → Roles: Drag the F.R.I.D.A.Y role above your @Verified, @Spider-Verse, @Leader, and @Banker roles. Discord prevents bots from assigning any role positioned higher than themselves.
⚡ Result: When new members join, they can only see the #verification channel. F.R.I.D.A.Y immediately greets them with the 1-click verification card. As soon as they verify, F.R.I.D.A.Y automatically assigns the @Verified role, instantly unlocking the rest of your server!
👑 Role Hierarchy Notice: If the bot reports a role hierarchy error, simply open Discord Server Settings → Roles and drag the F.R.I.D.A.Y role higher up the list!

⚡ Faction Armory 1-Click Auto-Fill (Tampermonkey)

Auto-fill player name & quantity on Torn
