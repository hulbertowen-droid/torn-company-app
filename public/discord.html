🔒 How to Setup Channel Locking in Discord

Keep channels hidden until verified
  1. Lock Everyone Out: In Server Settings → Roles → @everyone: Set View Channels to OFF (❌ Denied).
  2. Unlock Verification Channel: Right-click your #verification channel → Edit Channel → Permissions: Set @everyone to View Channel: ON (✅).
  3. Grant Server Access to Verified: On main categories: Add your @Verified role and set View Channels: ON (✅).
  4. Position Bot Role on Top: In Server Settings → Roles: Drag the F.R.I.D.A.Y role above all member roles so Discord allows it to assign them.
⚡ Result: New arrivals can only see #verification until they 1-click verify. F.R.I.D.A.Y automatically assigns @Verified to unlock the server!

📖 3-Step Discord Developer Portal Setup Guide

How to generate your Bot Token, enable Privileged Gateway Intents, and invite the bot
▼
  1. Go to the Discord Developer Portal → click New Application. Name it F.R.I.D.A.Y. or your faction bot name.
  2. Click Bot in the sidebar → click Reset Token, copy the token, and paste it into Bot Token below.
  3. Under Privileged Gateway Intents, enable Presence Intent, Server Members Intent, and Message Content Intent. Click Save Changes.
  4. Go to OAuth2 → URL Generator. Under Scopes check bot and applications.commands. Under Bot Permissions check Send Messages, Embed Links (required for rich alert cards), and Mention Everyone.
  5. Copy the generated URL and open it to invite the bot into your faction server.
  6. In Discord, enable Developer Mode (User Settings → Advanced). Right-click your alert channel → Copy Channel ID. Paste it below into Alert Channel.
  7. Optionally right-click your Discord profile → Copy User ID to receive personal @mentions for urgent chain drop warnings.
⚠️ Embed Links permission required: If the bot role is missing Embed Links in your server or channel, Discord blocks rich alert cards and delivers them as unformatted plain text. Ensure the F.R.I.D.A.Y bot role has Embed Links and Send Messages.
