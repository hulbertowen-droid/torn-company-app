📖 How to create & invite a Faction Discord Bot ▼
  1. Go to the Discord Developer Portal and click New Application. Give it a name like "Faction Alerts".
  2. Click Bot in the left menu → click Reset Token and copy your Bot Token. Paste it into the Faction Bot Token field below.
  3. Scroll down to Privileged Gateway Intents. Enable Presence Intent, Server Members Intent, and Message Content Intent. Save Changes.
  4. Click OAuth2 → URL Generator. Under Scopes, check bot. Under Bot Permissions, check Send Messages and Mention Everyone.
  5. Copy the generated URL at the bottom and open it in a new tab to invite the bot to your Discord server.
  6. In Discord, enable Developer Mode (User Settings → Advanced). Right-click the alert channel → Copy Channel ID. Paste it below.
  7. Optionally right-click your own Discord profile → Copy User ID to enable personal pings on chain attack warnings.
